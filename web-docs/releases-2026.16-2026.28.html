Methodology

口径与限制

这是一份面向升级决策的归纳，不是 555 条 commit message 的机械转录。每条结论都回到目标标签的最终代码与关键提交核对。

  • 标签日期这些版本均为 lightweight tag，日期采用标签所指向提交的 commit date。
  • 提交口径tagA..tagB；该范围内没有 merge commit，因此总提交数与 --no-merges 一致。
  • 文件与行数使用两个标签端点的 git diff，会包含生成代码、依赖文件与机械重排，不等同于业务代码规模。
  • 回滚处理以目标标签最终行为为准；同区间落地后又撤销的改动只作为说明，不计为有效能力。
  • 来源主仓库 e2b-dev/infra 的 Git 历史、关键 diff、OpenAPI/proto 与 migration；另参考仓库内 API 变更总览。
